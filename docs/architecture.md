# 工程约定

## 标签关系与补标

Go `relations_version=1` 开放上下位和条件模式；`structure_editable`、`classification_runs` 仅控制新操作入口，不改变历史解释。关系/规则变更使用同一个 StructurePreview（完整统计、40 条分页、预览 token、409 后重新预览），不由客户端推算成员。

新点击标签和新增正向规则默认包含下位，新排除默认精确；旧 URL/规则缺少模式一律精确。tagScopes 写入 URL，API 用 ref→mode 的 tag_modes。列表与统计来自同一 workspace 修订，reconciling 时局部轮询，结束后权威核对。

ClassificationRuns/PlanBuilder/RunDetail 用 TanStack Query 管理有界计划与运行分页，独立局部 busy。预算确认前仅请求不调用模型的计划；同一用户意图保留 submission_key。取消、撤销、明确重试分别显示后果，撤销展示实际回退和已删除跳过数量。操作回执后后台刷新，不阻止阅读。401 仍统一清理全部私有查询缓存，生产不回退 demo。标签/分类定义都是用户内容，CN/EN 只切换界面文本。

- 应用装配负责路由和依赖注入，展示组件通过 props 接收数据与事件。状态编排集中在 `use-workspace-model`，不重复出现在文章和网站页面。
- 搜索与筛选属于 URL 状态；正在编辑的输入、弹出菜单属于局部状态；工作区的服务器快照与待保存编辑归 LiveStore，轻量服务状态归 TanStack Query，两者不重复保存同一资源。
- 演示数据与页面分离，具有显式演示身份；不要把模拟连接、令牌和调用量当作生产实现。
- Zod 校验位于 URL、持久化、API 等外部输入边界，避免强制断言掩盖数据不匹配。
- UI 组件可用 Radix/shadcn 的组合方式扩展，但其默认样式不是产品设计。共享组件不得引入具体业务 feature。
- 调色、字体、语义颜色集中在 `index.css`。新增样式优先复用原稿令牌，避免随意引入第二套主题。
- 依赖安装使用锁文件。CI 与本地使用同一 Node、pnpm、检查命令。Dependabot 每周提出依赖更新，合并前必须通过检查和设计对照。
- 测试覆盖关键行为和输入边界：国际化、持久化、URL 恢复、API 契约、阅读、搜索、管理与窄屏导航。避免逐行镜像实现的测试。

## 生产模式

- `VITE_DATA_MODE=live` 在构建时选择生产适配器；默认 demo 保持设计稿回归。生产失败不回退演示数据，不将书签或凭据写入浏览器持久存储。
- `production.ts` 验证 workspace 汇总合同，将后端稳定 tag_ref 映射为视图标签。首屏单请求、40条摘要分页，搜索、筛选、计数与时间统计由Worker完成；正文/编辑状态及合集成员按需读取。重复名称增加 term 标识，避免同名标签混用。
- `LiveStore` 是工作区唯一数据所有者，通过 useSyncExternalStore 提供快照。编辑立即进入内存草稿；标签和合集编辑面板关闭后提交，独立开关等操作使用 700ms 合并。提交期间仅禁用编辑控件，导航、文本选择和滚动保持可用；失败保留草稿与操作编号，允许显式重试或放弃并刷新。编辑中、实际提交、提交成功后更新列表使用不同状态，完成/关闭编辑器立即提交，独立开关保留700ms合并。进入设置时停止不可见正文请求。写入使用原快照的 expected_revision、内容/决策修订及每项唯一 operation_key，不自动重试覆盖冲突。
- 每批写入成功后重新读取服务端权威结果；失败保持原快照和草稿，重试复用每个操作的编号，通过服务端回执处理部分成功和响应丢失。只重新读取当前摘要页和已打开的文章状态，正文以版本校验复用有界内存缓存。工作区查询按完整筛选、日期和游标归一化，缓存最多8页/2MiB、有效60秒；详情最多8篇/8MiB，60秒内仅在正文及人工修订匹配摘要时直接复用，超过60秒重新鉴权并校验版本，正文最多保留5分钟。编辑前清空读取缓存并取消在途请求；手动刷新绕过新鲜度限制。刷新按钮重新读取权威摘要与当前详情。数据不会因读取失败伪装成保存成功。
- 生产状态面板单独使用 TanStack Query，每分钟读取一次真实计数。刷新/检查不会触发付费任务。
- 当前 NAS 合同没有独立 site kind、网站健康/定价、此页面用量接口。统一把书签显示为文章，不按域名猜测网站。新增类型使用稳定 ID，支持改名、颜色、AI/手动、停用和恢复；标签支持新增、改名、定义、别名、停用与恢复；删除移除当前定义与文章关联，保留历史记录，并暂停引用它的合集规则。内置标签走目录 delete 事务，自定义标签 DELETE 显式传 permanent=true，旧版 DELETE 的停用/恢复协议保持兼容。内置标签类型固定，内置语义维度至少保留一个可自动判定的标签。新增网站合集明确拒绝。
- 新界面运行在 8089，旧版容器和 8088 保持原配置。workspace摘要/详情、合集、标签目录、自定义标签由新服务使用服务端凭据直连共享 Worker 的新版内部接口，其余读写通过原服务。凭据仅在运行环境，绝不进入浏览器。后端使用 0068 增量迁移，保留旧协议和旧数据。

## 可扩展分类与合集

- 新类型和标签使用独立的修订号；已有 custom tag_ref 不随改名或移动类型改变。新增类型的 AI 判断使用类型名称、类型定义、标签定义与存档原文，不把所有类型强行解释为主题。
- Worker 的独立分类队列在五分钟调度内处理，有明确的模型、0.85 应用阈值、最多 16 个同批判断和输入上限；共享原有扩展预算（全局每天 20 次、单条每天 2 次）。该阈值是保守产品策略，并非真实模型效果验证。
- 类型和标签均可切换手动。人工添加、人工排除优先，内容或定义在请求期间变化时不写入过期结果；超时不立即重试付费调用。模型凭据只保存在 Worker secret。
- 合集保存完整 v2 规则（启用、任一/全部、排除、审核、仅人工确认），提供预览、回填、审核/忽略恢复、成员排序和移除。删除是可恢复状态，不删除资料正文。
- 人工确认规则通过关联来源区分自定义标签：AI 关联不能伪装成人工确认。

性能约束、缓存边界和测量方法见 [performance.md](performance.md)。

## 阅读布局与媒体

- 根视口固定为 `100dvh`；侧栏底部操作固定，标签区、资料列表、正文和检查器各自滚动。滚动不传递给页面外层。
- 请求结果携带筛选身份；未缓存的筛选切换不展示上一条件的列表和统计；同条件刷新保留已展示内容，成功后替换为服务端结果。目录尚未读取时，未知标签和合集不能退回全部资料。演示存储不参与生产初始化。
- 阅读器及媒体播放器分包按需加载。React Markdown + remark-gfm 渲染正文，禁止原始 HTML；`cairn-image:N` 只映射到详情返回的归档图片。外部图片不自动请求，避免跟踪和失效源链接。
- `components/media` 提供通用 Radix Dialog 图片预览与 Media Chrome 播放器；业务映射集中在 `article-content`。图片懒加载；视频进入阅读视口附近才读取 metadata，以真实宽高比显示首帧，播放前不自动播放。屏外视频和音频保持 `preload=none`；浏览器按需 Range 读取，metadata 实际传输量取决于媒体封装和浏览器。视频使用画面内渐变控件、倍速菜单、画中画和全屏，不固定 16:9，不裁切竖屏；ZIP 归档提供下载。失败、尚未归档均有明确提示。
- 媒体元数据随当前正文详情读取，服务器检查当前采集身份；摘要页不加载媒体。8089 的受限代理仅允许归档图片 GET 和媒体 GET/HEAD，服务端鉴权、图片隐私检查、Range/Content-Range 均保留。

## OCI Go 模式

`VITE_DATA_MODE=live VITE_API_BACKEND=go` 将已校验的工作区合同映射到同源 `/api/v1`，解开 Go 统一响应 envelope。首屏由后端 PostgreSQL 聚合，保留 40 条摘要和按需正文；相同缓存/草稿/版本冲突策略继续使用。Go 支持 article/site kind，旧 NAS 模式继续拒绝新增网站合集。

SessionGate 在会话确认前不挂载资料界面。口令只在 HTTPS 登录请求中发送；会话为 HttpOnly + Secure + SameSite=Strict cookie，写入附带独立 CSRF cookie 的值，服务端检查 Origin。退出或 401 时重载清空内存中的私有资料。浏览器不持久化书签或服务令牌。

图片和视频仅映射后端返回的当前归档 ID，使用 `/api/v1/media/{id}`。处理失败和原文缺失分别呈现；已有原文始终可以阅读和手动整理。既有设计布局、独立滚动和自适应媒体控件不变。

正式 Go 构建执行 `pnpm build:go`。新增 `pnpm test:go` 覆盖鉴权前数据隔离、CSRF 写入、退出和 Go 媒体合同；NAS 适配器仍由 test:live 验证。生产入口为 cairn.alpenl.com，独立于原 8088/8089，数据不会持续双写到旧库。

公开静态资源可通过构建参数 `CAIRN_ASSET_BASE` 指向独立 CDN；默认同源不变。API 与归档媒体保持同源鉴权。资源域名的缓存、CORS、CSP、旧哈希保留与发布顺序见 [性能约定](performance.md)。请求失败时必须结束加载并提供同条件重试，不能让结果身份不匹配变成永久加载。

## 标签删除回执

标签行在编辑图标旁提供独立删除入口；自定义类型可停用/恢复，也可明确确认后永久删除（含已停用类型）。内置类型保留。删除类型会清理所属标签与关联、暂停依赖规则，正文和审计历史保留。

清洁草稿下的删除立即提交独立命令，绕过 700ms 编辑合并。Go 在删除事务中返回精简 `deletion` 回执：删除的稳定 tag_ref、类型 ID、目录修订和受影响文章/合集的实际修订。前端确认成功后按回执更新数据并解锁控件，统计仍由服务端后台重读；不等待整页下载。新编辑会取消旧回读，避免过期结果恢复已删除标签。目录/已加载实体版本发生跳跃时必须先回读，不能替并发修改提升旧草稿的 expected_revision。

超时或结果不确定的失败保留目标与 operation_key，通过明确重试取得原事务回执；不假装删除成功。旧 NAS 无回执时保留原来回读后解锁的兼容路径。包含未保存编辑时先完成版本受控的草稿流程，不丢弃其他编辑。上线顺序为 Go 后端、再前端，旧版客户端忽略新增可选字段。

Go 模式的内置类型仍保留，但允许删空标签、停用最后一个标签或将其切为手动；空类型不提供 AI 候选，整个词表没有自动候选时直接完成分类且不调用模型。NAS 旧合同的最后自动标签限制保持。单次删除被服务端明确按策略拒绝时，清除未执行意图并解除草稿锁，显示“数据未更改”；网络失败和多命令批次仍保留幂等重试，不混同处理。

## 标签 P1 分类依据

仅 Go 目录显式返回 classification_version=1 时开放 AI 判断依据。展示名、别名与 aiLabel 独立，日常改名可选择保留旧名为别名；同类型冲突阻止，跨类型视图追加类型信息，API 仍按 ref/term 操作。分类定义或 AI 名称变化必须显式选择变化类别。新版本与历史未知/复查数量来自后端，前端不重算分类，也不自动补标。

单条已有标签/类型元数据编辑采用同事务 catalog 回执，保存成功后立即解除编辑锁，再后台读取统计。后台请求会在新草稿出现时取消，不能覆盖草稿。目录修订跳跃需权威回读。单条明确校验拒绝允许修正草稿；网络结果未知保留原 operation key，多命令批次可能部分成功时继续原恢复保护。NAS 或旧 Go 未声明能力时不显示新字段、不提交新协议。AI 关闭、停用、删除的提示按现有有效关联规则分别解释。未知/复查仅为注解，不隐藏旧标签。

## 侧栏紧凑排版

`CompactFlow` 以实际按钮宽度执行确定性的 best-fit decreasing 排版，DOM 顺序与键盘顺序一致；视觉排序不写入标签设置或后端。侧栏缩小缩进，长标签保留完整 title 并在可用宽度内省略。宽度变化、字体加载完成、名称/计数/成员变化触发测量；选择状态不触发测量。排版结果按容器宽度、稳定键、实测宽度缓存，最多 128 份，仅在会话内存中保存，折叠后重新展开可复用，不写浏览器持久存储。

独立滚动区域使用 `scroll-quiet`：包括 hover 时均隐藏原生滚动条，保留滚轮/触摸/键盘滚动，避免滚动条占宽引起换行抖动。侧栏底部操作固定。

## 分类阶段状态

Go 摘要/详情附带 classificationStatus 和 processingStatus。未执行、排队、判定中、判定完成、结果待核对分别显示；判定完成允许零标签，不伪造正例。原文与摘要可用时，失败的分类不隐藏摘要或已有标签。旧服务未返回字段时保留原有提示。不限次数的配额以本地化文案显示，不能显示负数余额。
